How to cite

The data and text on this site are free to use with attribution (CC BY 4.0). No advance notice or permission is required.

Check the primary source first

Every figure on this site is transcribed from a government publication. Each page’s table carries a source URL and page number for every row. When citing a figure itself, please go to the primary source where possible. Transcription errors can happen — any we find are recorded, not deleted, in the corrections log.

What zurekei is best cited for isn't the bare figures so much as the pairing of forecast and actual, how they're laid out, and the ongoing record over time.

How to cite

Three levels of granularity, each in a form you can copy directly.

The site as a whole
Zurekei, "The gap between government forecasts and actual outcomes," https://zurekei.org/en/ (accessed YYYY-MM-DD)
A single page
Zurekei, "Tax revenue," https://zurekei.org/en/chart/tax-revenue (accessed YYYY-MM-DD)
The data directly
Zurekei, tax_revenue_forecast.csv, https://zurekei.org/data/tax_revenue_forecast.csv (accessed YYYY-MM-DD)

Replace YYYY-MM-DD above with the date you actually viewed the page (e.g. 2026-07-31).

Please always include the access date. This site is updated a few times a year to match government releases, and once a final figure is published, past rows get rewritten. Without an access date, there's no way to later tell which finalization stage the figure you saw belonged to.

URLs don't break

The canonical URL is the extension-less form (e.g. /en/chart/tax-revenue).

The old /chart?m=... form still redirects via JavaScript, but please cite the canonical URL instead. Because the redirect runs in JavaScript, crawlers and social-media link previews that don't execute it land on the indicator list page instead.

Found an error?

If you spot an error in the data or the text, please get in touch via the contact form. Corrections are recorded, not deleted, in the corrections log.
