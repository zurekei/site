# data/gdp_forecast.csv について

内閣府「経済見通しと経済財政運営の基本的態度」の当初見通し(GDP成長率)と、国民経済計算(SNA)の実績値を年度単位で並べたデータ。

## 収集範囲

- 見通し(forecast_real): FY1980〜FY2025
  - FY1998〜FY2025は内閣府アーカイブの閣議決定版(閣議了解版は同一見通しの前段階のため除外)
  - FY1980〜FY1997は国会会議録の経済演説(下記「出典」参照)
- 見通し(forecast_nominal): FY1980〜FY1987・FY1989〜FY2025。残る未収集はFY1988の1年度のみ(下記「未着手」参照)。FY1982〜FY1987は国会会議録の委員会質疑・政府答弁から収集(経済演説は名目にふれないため。行ごとの`forecast_source_url`の`名目:`部分を参照。すべてGNPベース)。FY1989〜FY1997は財務省『平成財政史』の記述から収集(FY1993以前はGNPベース)
- 実績(actual_real / actual_nominal): FY1981〜FY2024(FY1980は接続元系列の起点で成長率算出不能)
- FY2025の実績値は年度未終了のため空欄
- 実績のヴィンテージ(actual_basis): 実績値がどの基準の系列かを列に明示。FY1981〜FY1994は`2015base-ref`(2015年基準の簡易遡及・参考系列)、FY1995〜FY2024は`2020base-final`(2020年基準の確報)。チャートではFY1994以前を破線で描き、FY1994/1995の境目に細い縦線(シーム)を引いて基準が変わることを示す
- 見通しの概念基準(forecast_basis): 見通しがGNP(国民総生産)ベースかGDP(国内総生産)ベースかを列に明示。FY1980〜FY1993は`gnp`、FY1994〜FY2025は`gdp`。チャートではGNPベース期(FY1980〜1993)を淡い背景帯＋「GNPベース期」ラベルで示し、実績のGDPとは概念が異なることを可視化する。実績ヴィンテージのシーム(FY1994/1995)とは別レイヤーで、帯の右端(FY1993/1994)はシームの1年左にずらして描き分けている

## 出典

- 見通し(FY1998〜): https://www5.cao.go.jp/keizai1/mitoshi/mitoshikako.html 掲載の各年度PDF/HTML(行ごとのforecast_source_urlを参照)
  - FY2000は現在の内閣府URLが本文消失のスタブページ化していたため、Wayback Machineのアーカイブ経由で確認
  - FY1999の名目値は別添「主要経済指標」表が画像(gif)のため、画像を直接読み取って確認
- 見通し(FY1980〜FY1997): 国立国会図書館「国会会議録検索システム」に収録された**経済企画庁長官の経済演説**(通常国会冒頭の政府four演説の一つ)。政府が閣議決定した当該年度の経済見通しの成長率を、大臣が本会議で読み上げた記録
  - 内閣府のアーカイブページはFY1998始まりで、それ以前の閣議決定文書本体はウェブ上に存在しない。経済演説は全文が恒久URLで公開されており、同一内容が衆議院・参議院の2つの会議録に独立して記録されているため、転記の相互検証ができる
  - 収録した数値はすべて衆議院本会議の会議録から採り、参議院の会議録と全18年分が一致することを確認済み
  - 一部の年度は翌年度の演説が前年度の「当初見通し」を再掲しており、追加の裏取りに使った(例: FY1980の4.8%はFY1981演説の「当初の見通しどおり、四・八％程度」、FY1983の3.4%はFY1984演説の「当初見通しの三・四％程度」、FY1984の4.1%はFY1985演説の「昨年初めの当初見通しの四・一％程度」)
  - FY1997は財務省財務総合政策研究所『平成財政史』が「名目3.1％程度、実質1.9％程度」と記載しており、実質1.9%を外部から確認できた — https://www.mof.go.jp/pri/publication/policy_history/series/h1-12/1_2_2.pdf
- 見通しの名目(FY1989〜FY1997): 財務省財務総合政策研究所『平成財政史 平成元〜12年度』第1巻の本文記述より収集。経済演説が名目にふれていないため、閣議決定された経済見通しを引用している同書の記述を採った。行ごとの `forecast_source_url` の `名目:` 部分を参照。FY1989〜FY1993はGNP、FY1994〜FY1997はGDPベース
- 実績:
  - FY1981〜FY1994: 2015年基準・簡易遡及の参考系列(内閣府ESRI、令和3年12月8日公表) — https://www.esri.cao.go.jp/jp/sna/data/data_list/h27_retroactive/
  - FY1995〜FY2024: 2020年基準・2008SNA・2024年度国民経済計算年次推計(正式系列) — https://www.esri.cao.go.jp/jp/sna/data/data_list/kakuhou/files/2024/2024_kaku_top.html

## 既知の注意点

- **基準改定によるヴィンテージ差**: GDP統計は基準年改定のたびに過去に遡って数値が改定される。本CSVの実績値は最新の改定値で、しかも単一系列ではなくFY1994以前(2015年基準の参考系列)とFY1995以降(2020年基準の確報)の継ぎ接ぎである。どちらも「当時公表された値」ではなく後年の改定値なので、古い年度ほど「見通しと実績のズレ」に予測誤差だけでなく統計改定ドリフトが混ざる。どの基準かは`actual_basis`列に明示し、チャート上も破線＋シーム線で境目を可視化した(Phase 1)。さらに、同じ年度が基準改定でどれだけ動いたかの幅そのものを、基準別の実績系列(`data/gdp_vintages.csv`、平成2年〜2015年の6基準)から求め、チャート背景に淡い包絡帯(各年の最小〜最大)として可視化した(Phase 2)。例えばFY1985の実質成長率は基準により4.1〜6.3%(2.2ポイント幅)動いており、予測誤差と同オーダーである。ただしこれは「基準別の後年推計を束ねた幅」であって「当時公表された初回確報ヴィンテージ」そのものではない。後者を集めれば予測誤差と改定ドリフトを厳密に分離できる(下記「未着手」Phase 2続き)。
- **FY1993以前の見通しはGNPベース**: 政府経済見通しの主要指標は、FY1994(平成6年度)の経済演説で初めて「国内総生産の実質成長率」と明記され、FY1993以前の演説は「実質経済成長率」としか述べていない。当時の主要指標は国民総生産(GNP)であり(FY1993については国会質疑でも「ＧＮＰ四百九十五兆三千億円、名目成長率四・九％、実質三・三％」と言及されている)、実績値のGDPとは概念が異なる。FY1980〜FY1993の見通しと実績を比べる際はこの差が乗ることに注意。この差は`forecast_basis`列に明示し、チャート上はGNPベース期を淡い背景帯で可視化した(実績ヴィンテージの破線＋シームとは別レイヤー)。
- **FY1980〜FY1997のforecast_published_dateは演説日**: 閣議決定日ではない。閣議決定は演説の数日前だが、日付を一次資料で確認できないため演説日を記録している。
- FY2011の見通し文書のみ章立てが「Ⅰ〜Ⅳ」形式(通常は「１〜３」)で、対象年度見通しは「Ⅳ．平成23年度の経済見通し」に該当。
- FY2013・FY2015は閣議決定日が2月(通常は1月)。政権交代直後の年度で決定が遅れたため。

## 未着手(今後の作業)

- **FY1988の名目成長率見通し**(残り1年度)。FY1982〜FY1987は国会会議録の委員会質疑・政府答弁から%表記の直接言及を収集して反映済み(経済演説は名目にふれないため。各発言中の実質値がCSV既存値と一致することを裏付けとした)。FY1989〜FY1997は財務省『平成財政史』(平成元〜12年度)の本文記述から反映済み。残るFY1988だけは同種の会議録探索でGNP名目成長率の数値言及が見つからず未収集。確実な一次資料は次の2つ
  - 大蔵省/財務省編『国の予算』昭和63年度版に「政府経済見通し」の主要指標表が載る(財務省『平成財政史』が出所として明示している)。ウェブ公開はなく、国立国会図書館等で現物にあたる必要がある
  - 経済企画庁「昭和63年度の経済見通しと経済運営の基本的態度」閣議決定文書原本(閣議決定日は『平成財政史』の記述から特定できる)
- FY1989とFY1993〜FY1997の消費者物価見通し。経済演説にその年度の消費者物価上昇率の数値がなく、`cpi_forecast.csv` でこの6年分が空欄のまま
- 実績値のヴィンテージ(基準改定)の表現。**Phase 1(基準の明示・破線＋シーム線での可視化・`actual_basis`列)と、Phase 2の第一段(基準別系列を束ねた包絡帯の可視化・`data/gdp_vintages.csv`)は対応済み**。残るのはPhase 2の本丸=「当時公表された実績」(各年度終了1〜2年後の初回確報ヴィンテージ)を別系列(例: `actual_real_original` 等)として収集すること。包絡帯は「後年の基準別推計がどれだけばらつくか」を示すが、初回確報は「予測が立てられた当時、世の中が見ていた実績」であり別物。これを集めれば「ズレ＝予測誤差＋改定ドリフト」を厳密に分解できる。当時の『国民経済計算年報』各年版を年ごとにあたる必要があり(ESRIのウェブには旧基準の再推計系列は残るが初回確報ヴィンテージそのものは残らない)、見通し収集と同規模のデータ収集プロジェクト。急がない
- 名目/実質の乖離だけでなく、関連指標の追加余地(消費者物価は`cpi_forecast.csv`として追加済み)

## 対応済み(旧「未着手」からの繰り上げ)

FY1980〜FY1997の実質成長率見通し(18年分)は国会会議録の経済演説から収集し、`gdp_forecast.csv` に反映済み。同じ演説から消費者物価の見通しも12年分取れたため `cpi_forecast.csv` にも反映した。

FY1989〜FY1997の名目成長率見通し(9年分)は財務省『平成財政史』の本文記述から収集し反映済み(経済演説が名目にふれていないための補完。FY1993以前はGNPベース)。出典は行ごとの `forecast_source_url` の `名目:` 部分に個別記録している。

税収見積もり(Phase 2)・出生率(Phase 3)はいずれも実装・公開済み。現在サイトが扱う指標は次の8系列 + 出生率ページ。

- `gdp_forecast.csv`(実質・名目) / `tax_revenue_forecast.csv` / `cpi_forecast.csv` / `unemployment_forecast.csv` / `current_account_forecast.csv` / `bond_issuance_forecast.csv` / `jgb_total_issuance_forecast.csv`
- `fertility_forecast.csv` + `fertility_actual.csv`(専用ページ `/fertility`)

# data/gdp_vintages.csv について(基準改定ヴィンテージ)

実質GDPページ・名目GDPページの背景に描く「包絡帯」の元データ。**同じ年度のGDP成長率が、統計の基準改定でどれだけ書き換わってきたか**を、基準ごとの後年推計系列として並べたもの。すべて内閣府ESRIがウェブで公開している一次資料の統計表(xls/csv)から、表に載っている対前年度成長率をそのまま転記した(水準からの再計算はしていない)。

- 列: `fiscal_year`・`basis`・`actual_real`・`actual_nominal`・`actual_real_source_url`・`actual_nominal_source_url`・`notes`。**1行=(年度 × 基準)の縦持ち**で、1つの年度に最大6行が並ぶ(2026-08-04に横持ちから移行。経緯は `data/README.md` の該当節)
- 年度=会計年度(4月〜翌3月)。数値は原表どおり小数第1位まで
- チャートは各年の「値がある基準が2つ以上ある場合」に最小〜最大を取り、淡い帯として描く。1系列しかない年(FY1980以前やFY2004以降など)は帯を描かない
- **すべてGDP(国内総生産・国内総支出)ベース**。GNP系列は含まない(見通し側のGNP/GDP問題とは独立に、実績の改定幅だけを表す)
