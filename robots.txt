#
# このサイトの目的は参照されることなので、拾われる側の障害は極力なくす。
# 一方で「予測と実績のズレを記録し続ける計器」という性格上、記録が引用元として
# 名前ごと残ることに意味があり、匿名の学習素材として溶けることには意味がない。
#
# ■ なぜダッシュボードだけに任せないのか
#   ここに書いてある内容は Cloudflare の AI Crawl Control 側の設定と重複している。
#   それでも repo 側に書くのは、ダッシュボードの設定が画面外で効いていて気づけない
#   事故を2回踏んでいるため(Pages の環境変数名の先頭空白 / 下記の Managed robots.txt)。
#   **バージョン管理されていて diff が取れる側を正とする。**
#   ダッシュボードを変えたらこのファイルも合わせること。
#
# ■ Cloudflare Managed robots.txt について
#   Cloudflare は配信時に、独自のブロック規則をこのファイルの「前に」連結できる。
#   その状態では、ここに何を書いても上の規則を消せない。
#   **実際の配信内容は必ず本番で確かめること**(ローカルのファイルとは違う):
#     curl -s https://zurekei.org/robots.txt
#
# ■ 読み違えた記録(繰り返さないため)
#   Disallow: / という文字列を見て「AI引用が塞がれている」と判断したが、誤りだった。
#   Cloudflare はボットを3カテゴリに分けており、対象は AI Crawler(訓練用)だけ。
#   引用に効くのは AI Search(OAI-SearchBot / Claude-SearchBot / PerplexityBot)と
#   AI Assistant(ChatGPT-User / Claude-User 等)で、こちらは別枠。
#   さらにその前段では、UA を偽装して 200 が返るのを見て「ブロックなし」と判断していた。
#   **同じ対象を粗く見て2回違う結論を出している。層を1つ見ただけで決めない。**

# ■ Content Signals について(下の Content-Signal 行の意味)
#   これは contentsignals.org の規約で、robots.txt の宣言に権利留保の意味を
#   持たせようとするもの。定型文は Cloudflare の Managed robots.txt に入っていた
#   ものを、こちらに移した(Managed を切っても意思表示が消えないようにするため)。
#   法的な効き目は評価できないが、入れる判断に評価は要らなかった。
#   数行増えるだけで、効くなら方針どおりの方向にしか働かず、効かなくても損はない。
#
#   このサイトの宣言は3つ:
#     search=yes    検索インデックスと検索結果への表示は歓迎(AI要約は含まない定義)
#     ai-input=yes  AI回答を作るときに参照するのは歓迎 ← 引用に効くのはこれ
#     ai-train=no   学習・ファインチューニングの素材にすることは断る
#
# ■ ai-train=no とCC BYの関係(2026-07-29、ライセンス決定に伴う追記)
#   このサイトはデータ・本文をCC BY 4.0(表示すれば再利用自由)で公開している。
#   CC BYには「学習だけを除外する」条項が無い。表示さえすれば学習も許すことに
#   なるので、ここの ai-train=no は「ライセンス上の法的な制限」ではなく、
#   「意思表示・お願い」に格下げされる。CC BYを守ってこのサイトを引用しつつ、
#   学習にも使うことは、ライセンス上は妨げられない。
#   「CC BYにしたので学習も自由です」という意味ではない。事実の順序は逆で、
#   ライセンス(表示すれば再利用可)を先に決めた結果、学習だけを狙い撃ちで
#   禁じる法的な手段が無くなった、というだけである。意思としては断ったままで、
#   宣言(Content-Signal・下記の個別クローラ拒否)も変えない。効くかどうかは
#   別として、効くなら方針どおりの方向にしか働かない、という判断は変わらない。
#
