# 方針(2026-07-29): 検索とAI回答への引用は歓迎する。学習用の一括収集は断る。
#
# このサイトの目的は参照されることなので、拾われる側の障害は極力なくす。
# 一方で「予測と実績のズレを記録し続ける計器」という性格上、記録が引用元として
# 名前ごと残ることに意味があり、匿名の学習素材として溶けることには意味がない。
#
# ■ なぜダッシュボードだけに任せないのか
#   ここに書いてある内容は Cloudflare の AI Crawl Control 側の設定と重複している。
#   それでも repo 側に書くのは、ダッシュボードの設定が画面外で効いていて気づけない
#   事故を2回踏んでいるため(Pages の環境変数名の先頭空白 / 下記の Managed robots.txt)。
#   **バージョン管理されていて diff が取れる側を正とする。**
#   ダッシュボードを変えたらこのファイルも合わせること。
#
# ■ Cloudflare Managed robots.txt について
#   Cloudflare は配信時に、独自のブロック規則をこのファイルの「前に」連結できる。
#   その状態では、ここに何を書いても上の規則を消せない。
#   **実際の配信内容は必ず本番で確かめること**(ローカルのファイルとは違う):
#     curl -s https://zurekei.org/robots.txt
#
# ■ 読み違えた記録(繰り返さないため)
#   Disallow: / という文字列を見て「AI引用が塞がれている」と判断したが、誤りだった。
#   Cloudflare はボットを3カテゴリに分けており、対象は AI Crawler(訓練用)だけ。
#   引用に効くのは AI Search(OAI-SearchBot / Claude-SearchBot / PerplexityBot)と
#   AI Assistant(ChatGPT-User / Claude-User 等)で、こちらは別枠。
#   さらにその前段では、UA を偽装して 200 が返るのを見て「ブロックなし」と判断していた。
#   **同じ対象を粗く見て2回違う結論を出している。層を1つ見ただけで決めない。**
